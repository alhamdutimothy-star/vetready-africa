# ADR 0003: Versioned diagnostic evidence and development plans

Status: accepted within the founder-authorized Phase 2 scope. Professional definitions remain proposed.

Retain the original group identities and add separately versioned assessable children and criteria with reusable group mappings. A question version maps through an assessment blueprint to a pathway, group and child; the domain is a normalized pathway/group relation. Assessment/item identities and content versions are separate, with immutable delivery snapshots and append-only item retirement.

Diagnostic correctness, human rubric observations, evidence facets and evidence review statuses are independent concepts. No knowledge or course event upgrades practical competence. Demo delivery is possible while formal validation is pending, but demo evidence cannot close professional gaps or be verified. Online simulation/practical/workplace placeholders cannot create observed-performance verification.

Compute current gaps rather than storing another independently mutable candidate-state table. Save requirement/evidence/gap snapshots when creating plans, using repeatable-read isolation and an engine version. Optional role targets add requirements to the same child evidence rather than copying competencies. Version changes do not silently transfer evidence.

Use per-item criterion rubrics with qualitative observations while numerical professional thresholds/weights are unapproved. Objective software examples may have exact answer keys, but no raw total is an employability/readiness score. Verification requires approved non-demo content, assigned human review and independent moderation of the latest review. Production approval is not exposed until governance is validated.

Trade-offs: live child-level external evidence and safe file/image delivery require a later storage/supervision milestone; pending requirements cannot establish final readiness; generic plan activities need governed module mappings; strict version matching may surface gaps after revisions, requiring an explicitly approved equivalence policy later. None of these is resolved by inventing professional standards.

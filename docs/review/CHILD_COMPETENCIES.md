# Proposed assessable child competencies

Current Phase 2 decision: Google Drive review is deferred and is not a blocker. No Drive material was reviewed. The proposed catalog is accepted as the working foundation, not formal professional validation. Historical access-review notes below describe the earlier checkpoint.

69 proposed child identities cover all 47 current organizing groups. Codes below are review identifiers, not seeded database records. Shared rows map to multiple groups without duplicate identities. No Drive file or external authoritative standard was reviewed; none of these definitions claims source-backed approval.

K = factual/conceptual knowledge assessment; C = case, calculation, dataset or written performance; P = observed practical/simulation task; W = corroborated workplace evidence; M = more than one distinct evidence mode, explicitly listed. W is not employer opinion alone. Routes are proposals, not activated gates. K may support prerequisites even where C/P is the proposed primary route.

Contexts carry species, system/stage, scale, site/product, geographical applicability, real/simulated setting, supervision, date, assessor and evidence type. No automatic cross-context transfer. P/simulation cannot certify a claim of field execution.

## Evidence artifacts by route

| Route | Suitable artifacts                                                                                                       |
| ----- | ------------------------------------------------------------------------------------------------------------------------ |
| K     | Marked answers linked to a reviewed item version and concept                                                             |
| C     | Workbook with formulas; written reasoning; case report; annotated specification; calculation working                     |
| P     | Authorized assessor rubric, observations, task output and consented recording where justified                            |
| W     | Attributed work record, verified employment/context, corroboration and review; no raw supervisor rating as certification |
| M     | Separate criterion-level decisions linked to each required evidence mode, not one averaged result                        |

All source mapping remains pending. A learning outcome can be supported by training material without that material being approved as an assessment or numerical standard. No nutrient values, doses, pass marks, weights, mandatory gates or final readiness scores are proposed in this catalog.
